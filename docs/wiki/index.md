# Wiki Management

This repository keeps project documentation in git so it is reviewable.

## Layers

- `AGENTS.md`: top-level operating contract
- `docs/index.md`: lazy-load navigation
- `docs/rules/`: process guidance
- `docs/patterns/`: repeatable implementation guidance
- `docs/knowledge/`: durable project memory
- `docs/dev-wiki/`: synthesized project knowledge

## Maintenance

- Prefer stable markdown files over chat-only decisions.
- Promote active practice into durable docs.
- Keep generated artifacts out of the wiki unless intentionally stored as source
  material.
