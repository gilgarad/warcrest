# 게임 컨셉: 갈림길 정찰대 (가제)

NHN `nan2026` AI 게임잼 제출용 컨셉 문서. 2026-07-23 세션에서 사용자와
상의해 확정. 확정된 항목은 "결정됨", 아직 흔들릴 수 있는 항목은
"가안"으로 표시.

## 한 줄 소개

디아블로류 던전 안을 실제로 이동하며(3인칭, 안개 시야+미니맵) 적과
부딪혀 전투하고, 감옥에 갇힌 동료를 직접 찾아가 구출해 대열을 늘리는
실시간 던전 탐험 액션. 전투는 파타퐁식 커맨드로 처리.

## ⚠️ 방향 정정 (2026-07-23)

첫 구현은 갈림길을 "왼쪽 길/오른쪽 길" 버튼 메뉴로 추상화한 로그라이트
카드 게임이었는데, 이는 사용자가 원래 예시로 든 "디아블로 던전에서
실제로 움직이며 적을 죽이고 동료를 구출" 이미지와 어긋났다. 사용자
피드백을 받고 즉시 방향을 바로잡음: 아래 내용은 정정된 최종 방향이고,
메뉴 기반 버전은 폐기(`docs/dev-wiki/log.md` "MVP 첫 구현"/"던전 탐험형
재설계" 항목 참고).

## 장르/분위기 (결정됨)

- 순발력 승부가 아니라 "잠깐 멈춰 생각하는" 페이스 — 다만 이동 자체는
  실시간(화살표/WASD), 메뉴 클릭이 아님.
- 로그라이트: 던전 하나가 3~5분 분량, 매 판 절차적으로 새로 생성됨 →
  재도전 유도, 짧은 세션에도 심사위원이 여러 판 돌려볼 수 있음.

## 핵심 루프 (구현됨, 세부는 프로토타입하며 다듬을 것)

1. 탑다운 2D, 캐릭터 주변만 보이는 제한 시야(안개) + 화면 우상단
   미니맵 — 디아블로 던전 진입 레퍼런스 그대로.
2. 방향키/WASD로 병사를 실시간 이동. 절차적으로 생성된 통로+갈림길을
   실제로 걸어서 탐색.
3. 던전 안에 배치된 적/포로에게 다가가면: 적은 접촉 시 전투 발동,
   포로는 접촉 시 자동 구출(대열 합류) — 메뉴 클릭이 아니라 이동 자체가
   상호작용.
4. 승리: 미션 지점(깃발) 타일에 도달. 패배: 대열 전멸(전투 패배로
   마지막 대열원까지 잃으면).

## 전투 시스템 — MMO 핫바식 쿨타임 슬롯 (결정됨, 2026-07-23 두 번째 정정)

- 적과 부딪히면(던전 안에서 실제로 접촉) 이동이 멈추고, 화면 오른쪽에
  **항상 떠있는** 공격/방어 슬롯 패널이 활성화됨.
- 1차 정정(첫 번째 팝업 박스 → 상시 패널)에 이어, 2차 정정: "정해진
  순서를 입력하고 공용 타이머가 끝나기 전에 처리" 방식이 사용자가 원한
  "MMORPG처럼 슬롯에 미리 배치해두고 쿨타임 끝날 때마다 적재적소에
  누르는" 느낌과 다르다는 피드백. `systems/combat.ts`를 전면 재작성:
  - 적은 HP를 가짐(난이도에 따라 3~7 정도).
  - 슬롯은 각자 독립된 쿨타임을 가짐 — 공격(쿨타임 짧음)은 누르면 적
    HP를 깎고, 방어(쿨타임 김)는 누르면 짧은 가드 윈도우가 열림.
  - 적도 자체 타이머로 주기적으로 공격 — 그 순간 가드 중이 아니면
    대열이 하나 줄어듦. 적 HP가 0이 되면 승리.
  - 슬롯은 현재 2개(공격/방어) — `docs/dev-wiki/log.md` "MMO 핫바 전투 +
    등각 투영 재설계" 항목 참고.

## 대열(스쿼드) 시스템 (결정됨, 비주얼 2026-07-23 수정)

- 포로를 구출할수록 뒤에 병사가 붙음. 전투에서 맞으면 앞줄부터 하나씩
  손실.
- 비주얼은 한 줄로 졸졸 따라오는 "스네이크" 대신, 리더 주변에 느슨하게
  뭉쳐서 같이 움직이는 클래시 오브 클랜류 "무리" 형태로 변경
  (`DungeonScene.squadOffset()`).
- 병종이 섞일수록 전투 슬롯의 폭이 넓어짐(위 전투 시스템과 연결) —
  아직 미착수.

## 아트 스타일 (결정됨, 2026-07-23 두 차례 톤 정정)

- AI 생성 픽셀아트가 원안이었으나, 이 환경에 이미지 생성 도구가 없어
  Phaser Graphics로 직접 그리는 벡터 기반 "가분수" 캐릭터로 대체 중
  (`src/gfx/chibi.ts`). 저작권 이슈는 이 방식이 오히려 원천 차단.
- **1차 정정**: 첫 던전 버전이 "80년대 게임 같다"는 피드백 → 탑다운
  상태에서 캐릭터 하이라이트/셰도우+아웃라인, 벽 입체 블록, 바닥 그림자
  추가.
- **2차 정정 (더 구체적)**: 사용자가 "추상적으로 말한 것 같다"며 세
  가지로 명확히 재지시 — (1) 디아블로 같은 등각(대각선 위) 투영, 이
  게임의 미로가 사실상 디아블로 던전, (2) 톤/밝기/움직임은 클래시 오브
  클랜·클래시 로얄처럼 밝고 채도 높고 탄력있게, (3) 병력은 클래시처럼
  무리지어 이동. 대응:
  - **진짜 등각 투영**(`src/gfx/iso.ts`)으로 전면 전환. 진짜 3D 렌더링은
    이 환경에서 불가능함을 사용자에게 먼저 알리고 확인받은 뒤 진행.
  - 캐릭터를 더 통통하고 채도 높은 팔레트로 재설계(밝은 파랑 병사/빨강
    적/초록 포로), 두꺼운 아웃라인과 강한 하이라이트로 광택 느낌.
  - 이동 시 통통 튀는 바운스(squash/stretch)를 추가해 움직임에 탄력감.
  - 세부 구현은 `docs/patterns/README.md`, 결정 배경은
    `docs/dev-wiki/log.md` "MMO 핫바 전투 + 등각 투영 재설계" 참고.

## 카메라/스케일 (결정됨, 2026-07-23 등각 전환으로 재조정)

- 1차 정정 때는 탑다운 상태에서 타일을 줄이고 시야 반경만 넓혔었음.
- 등각 전환 이후: 이동/충돌/시야 반경 로직은 기존 직교 격자 그대로
  유지하고, 화면에 그리는 위치만 등각 투영을 거침. 맵 전체가 한 화면에
  들어갈 필요가 없어져서(플레이어를 따라가는 카메라로 전환) 던전
  크기는 화면 크기가 아니라 재미있는 탐험 분량 기준으로 정함.

## 임팩트 포인트 / 플랫폼 (결정됨)

- 플랫폼은 **웹만** — 브라우저 실행, GitHub Pages 배포 후보.

## 스코프 리스크 (에이전트 메모, 사용자에게 플래그함)

로그라이트 절차 생성 + 파타퐁식 커맨드 전투 + 대열 관리 + AI 생성
픽셀아트 조합은 잼 스코프치고 요소가 많음. "완성도" 임팩트를 노린다면
MVP를 아래 순서로 좁혀 먼저 완결시키고, 남는 시간에 넓히는 게 안전:

1. ✅ 실시간 이동 던전 + 단일 전투 인카운터(커맨드 1종) + 구출 접촉 —
   2026-07-23 구현·검증 완료. 첫 시도(메뉴 기반)는 폐기하고 던전 탐험형
   으로 재설계, `docs/dev-wiki/log.md`의 "던전 탐험형 재설계" 항목 참고.
2. ✅ 대열 증감(구출/손실), 안개 시야, 미니맵 — 같은 구현에 포함됨.
3. 병종 다양화로 커맨드 덱 폭 넓히기 — 아직 미착수, 사용자가 의도적으로
   다음으로 미룸("일단 끝까지 해서 화면 보면서 지시").
4. 던전 생성 난이도 곡선(방 개수/분기 조절), 아트 폴리싱 — 미착수.

아트는 AI 이미지 생성 도구가 이 환경에 없어서, 실제 픽셀아트 대신
`src/gfx/chibi.ts`가 Phaser Graphics로 직접 그리는 벡터 기반 "가분수"
캐릭터로 대체 중. 나중에 실제 이미지를 구하면 텍스처 키만 바꿔 끼우면
되도록 렌더링 로직과 분리되어 있음.
