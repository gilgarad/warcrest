# 게임 컨셉: 갈림길 정찰대 (가제)

NHN `nan2026` AI 게임잼 제출용 컨셉 문서. 2026-07-23 세션에서 사용자와
상의해 확정. 확정된 항목은 "결정됨", 아직 흔들릴 수 있는 항목은
"가안"으로 표시.

## 한 줄 소개

병사 한 명으로 시작해 갈림길마다 선택하며 전진, 포로를 구출해 대열을
늘리고 파타퐁식 커맨드 전투로 적을 돌파하는 로그라이트 정찰 액션.

## 장르/분위기 (결정됨)

- 순발력 승부가 아니라 "잠깐 멈춰 생각하는" 페이스의 아케이드.
- 로그라이트: 런 길이 3~5분, 매 판 갈림길 순서가 절차적으로 달라짐 →
  재도전 유도, 짧은 세션에도 심사위원이 여러 판 돌려볼 수 있음.

## 핵심 루프 (가안, 세부는 프로토타입하며 다듬을 것)

1. 사이드뷰, 배경은 레이어드 패럴랙스로 pseudo-3D 느낌(완전 3D 아님).
2. 병사 1명으로 시작, 자동 전진 → 갈림길에서 정지 → 위/아래(또는 전방
   2~3갈래) 중 선택.
3. 선택 결과는 절차적으로 배정: 전투 조우 / 포로 구출(대열 합류) /
   자원·버프 / 함정 / 미션 목표.
4. 승리: 마지막 미션 지점 도달. 패배: 대열 전멸.

## 전투 시스템 — 파타퐁식 커맨드 (결정됨, 세부 가안)

- 비주얼보다 **플로우**가 핵심: 여러 병종이 섞인 대열이 만드는 커맨드
  조합이 재미의 본체.
- 적과 마주치면 화면 상단에 타이머 바가 빠르게 줄어듦(정밀 리듬 판정이
  아니라 "빨리 판단해서 누르기"에 가까운 긴장감).
- 플레이어는 미리 쌓아둔 공격/방어 "덱"에서 타이밍에 맞는 커맨드를
  선택해 입력 — 어떤 커맨드가 가능한지는 현재 대열의 병종 구성에 따라
  달라짐.
- MVP 단순화 후보: 적 유형별로 필요한 커맨드 아이콘이 뜨고, 타이머가
  0이 되기 전에 맞는 병종 커맨드를 순서대로 눌러 처리 — 정밀 리듬 게임이
  아니라 큐 소진형 판단 게임으로 구현.

## 대열(스쿼드) 시스템 (결정됨)

- 포로를 구출할수록 뒤에 병사가 줄줄이 붙음(비주얼 임팩트).
- 전투에서 맞으면 앞줄부터 하나씩 손실 — 스네이크처럼 대열이 늘고 줆.
- 병종이 섞일수록 전투 커맨드 덱의 폭이 넓어짐(위 전투 시스템과 연결).

## 아트 스타일 (결정됨)

- AI 생성 픽셀아트. 저작권 이슈 없는 방식으로 확보(대회 요건상 라이선스
  깨끗해야 함이 중요 포인트).

## 임팩트 포인트 / 플랫폼 (결정됨)

- 이번 제출에서 보여줄 임팩트는 **완성도/폴리싱** — 화려한 스코프
  확장보다 하나를 끝까지 다듬는 쪽.
- 플랫폼은 **웹만** — 브라우저 실행, GitHub Pages 배포 후보.

## 스코프 리스크 (에이전트 메모, 사용자에게 플래그함)

로그라이트 절차 생성 + 파타퐁식 커맨드 전투 + 대열 관리 + AI 생성
픽셀아트 조합은 잼 스코프치고 요소가 많음. "완성도" 임팩트를 노린다면
MVP를 아래 순서로 좁혀 먼저 완결시키고, 남는 시간에 넓히는 게 안전:

1. 갈림길 선택 + 단일 전투 인카운터(커맨드 1~2종)만 도는 최소 루프
2. 대열 증감(구출/손실) 붙이기
3. 병종 다양화로 커맨드 덱 폭 넓히기
4. 절차적 갈림길 생성 다듬기, 아트 폴리싱

## 미정 (다음에 정할 것)

- 게임 제목(현재 가제만 있음)
- 기술 스택/프레임워크
- 병종 종류와 개수, 커맨드 목록 구체안
- 미션(엔딩) 구조 — 고정 목표 하나인지, 스테이지형인지
