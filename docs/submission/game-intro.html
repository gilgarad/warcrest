Warcrest

전선과 요새를 두고 충돌하는 지휘 전장 — 넓은 대각선 레인 전장에서 자동 웨이브와 경제를 운영하는 전략 게임

1. 게임 개요

Warcrest는 좌하단 아군 본진과 우상단 적 본진 사이를 잇는 대각선 레인에서 병력이 자동으로 편성·이동·전투하는 오토배틀러형 공성 경제 게임입니다. 플레이어는 유닛을 직접 조작하는 대신, 자원 생산·일꾼 배치·시대(테크) 진행·거점 점령과 시설 건설을 운영하며 전황을 유리하게 만듭니다. 석기 시대부터 현대에 이르는 11개 시대를 거치며 병종과 시설이 점점 강력해지는 문명 발전형 진행이 핵심 루프입니다.

4. 게임 방법

4.1 시작하기

  1. 플레이 링크 접속 → 타이틀 화면에서 난이도를 선택합니다.
  2. 난이도 선택과 동시에 전장에 입장하고, 양측이 초기 병력으로 첫 웨이브를 자동 출전시키며 게임이 시작됩니다.

4.2 난이도

난이도적 자원 생산 배율적 연구(공/방) 최저 보정
초급×1없음
중급×21단계 보장
고급×32단계 보장
신×43단계 보장

4.3 목표와 종료 조건

상대 본진의 체력을 먼저 0으로 만들면 승리, 내 본진의 체력이 먼저 0이 되면 패배합니다. 병력은 정규 웨이브 주기마다 자동으로 편성되어 레인을 따라 전진하며, 상대 병력·타워와 자동으로 교전합니다.

4.4 조작 — 화면 하단 운영 패널 개요

조작설명
일꾼 배치 (+/−) 금/목재/식량/금속/연구 5개 자원 중 어디에 일꾼을 배정할지 실시간으로 재분배. 기본 일꾼 1명은 자원별로 항상 유지되며, 추가로 고용한 일꾼만 자유롭게 이동 가능.
일꾼 고용 / 연구 일꾼 자원을 소모해 일꾼 총원 자체를 늘림. 연구 일꾼은 즉시 연구 자원 생산에 투입됨.
즉시 웨이브 보유한 토큰을 소모해 다음 정규 웨이브를 기다리지 않고 즉시 병력을 출전시킴 (직전 웨이브 후 일정 시간의 쿨다운, 식량 조건 있음). 토큰은 시대 진행 시 지급됨.
시대 업 자원을 모아 다음 시대로 진행. 더 강한 병종·시설이 해금되고, 석기 → 청동기 → 초/중/후기 철기 → 르네상스 → 근대 초/후기 → 현대 초/중/후기까지 총 11단계.
거점 점령 전장 중앙의 거점을 클릭해 점령하면 방어 타워 / 병참(전투력 강화·마나 보급) / 조달소(치유) 중 하나를 건설할 수 있음. 재건·폐기도 클릭으로 조작.

5. 스크린샷으로 따라하는 상세 플레이 가이드

5.1 본진과 화면 구성

화면 좌하단에 아군 본진이 있고, 대각선 레인 반대편(우상단)에 적 본진이 있습니다. 본진 체력이 0이 되면 그 팀이 패배합니다. 병력은 이 본진에서 출발해 자동으로 레인을 따라 전진합니다.
화면 상단 자원 바: 금 / 목재 / 식량 / 금속 / 연구 5종. 왼쪽 정보 패널에는 현재 시대, 다음 웨이브까지 남은 시간(아군/적), 전장 병력 수, 보유한 즉시 웨이브 토큰 수가 표시됩니다.

5.2 일꾼을 늘리면 자원이 어떻게 오르는지

"일꾼 배치" 패널의 각 자원 행 옆 + / − 버튼으로 유휴 일꾼을 원하는 자원으로 재배치합니다. 아래는 실제 조작 순서입니다.

1시작 상태 — 금/목재/식량/금속에 각 1명씩 배치되어 있고(연구 0명), 상단 "일꾼 배치 0/4" 표시는 "유휴 일꾼 0명 / 전체 4명"이라는 뜻입니다.
2"일꾼 고용" 클릭 — 금/목재/식량을 각 10씩 소모해 일꾼을 1명 더 뽑았습니다. 표시가 "1 / 5"로 바뀌며, 이 1명은 아직 어느 자원에도 배정되지 않은 유휴 상태라 모든 자원 행의 + 버튼이 활성화(밝은 파란색)됩니다.
3금 자원의 + 클릭 — 유휴 일꾼이 금 생산에 배치되어 금 일꾼이 1명 → 2명으로 늘고, 유휴 인원은 다시 "0 / 5"로 돌아옵니다.
4다음 생산 틱(수 초 후) — 일꾼 2명이 붙은 금만 "+2"로 다른 자원(+1)보다 두 배 빠르게 오르는 것이 상단 자원 바에 초록색 팝업으로 표시됩니다. 이렇게 특정 자원에 일꾼을 몰아주면 그 자원만 선택적으로 빠르게 모을 수 있습니다.

5.3 전략 액션 버튼 4종

좌상단부터: 일꾼 고용(금10·목재10·식량10 소모, 일꾼 총원 증가), 연구 일꾼(금·목재·식량·금속 각 50 소모, 연구 생산에 즉시 투입), 즉시 웨이브(토큰 소모, 다음 웨이브를 기다리지 않고 즉시 출전), 시대 업(금35·목재20·금속28 소모, 다음 시대로 진행해 더 강한 병종/시설 해금). 버튼 아래 숫자는 각각 필요한 자원 비용입니다.

5.4 거점 점령과 시설 건설

레인 중앙의 건설 거점을 클릭하면 이렇게 이름표와 점령 상태 ("아군 점령" / "빈 건설 거점" 등)가 뜨고, 화면 우측에 건설 메뉴가 열립니다.
거점을 점령한 뒤 지을 수 있는 시설 3종 — 타워(적을 자동 공격), 병참(주변 아군 전투력 강화·마나 보급), 조달소(주변 아군 치유). 버튼 아래 숫자는 건설 비용이며, 지어진 시설은 재건/폐기도 같은 자리에서 클릭으로 조작합니다.
