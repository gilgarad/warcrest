# Documentation Rules

## Lazy Loading

- `AGENTS.md` is the top-level router.
- `docs/index.md` is the lazy-load catalog.
- Durable details belong in topic files, not in `AGENTS.md`.

## Placement

- process rules: `docs/rules/`
- implementation patterns: `docs/patterns/`
- project memory: `docs/knowledge/`
- synthesized long-lived knowledge: `docs/dev-wiki/`
- human-facing documentation policy: `docs/wiki/`

## Maintenance

- Update `docs/index.md` when adding or moving docs.
- Prefer links over duplicate summaries.
- Keep files atomic: one concern per file.
- Delete, archive, or mark stale docs.
